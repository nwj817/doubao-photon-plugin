# 豆包 AI 创作 · Photon 原生插件

将豆包（方舟大模型）的 AI 创作能力集成进 **Photon Studio** 的原生面板插件：安装后直接在 Photon「插件」菜单打开「豆包 AI 创作」，无需 MCP、无需外部客户端。

## 功能

左侧栏切换：

| 功能 | 说明 |
| --- | --- |
| 对话 | 统一自由对话：快速 / 专家模式、历史会话管理、可附图（本地 / 画布）、**对话内直接出图**（回复带图 + 一键置入画布） |
| 文生图 | Seedream 5.0 Pro / 4.5 文生图；**尺寸双模式**（固定比例×档位实时像素 / 自定义像素按模型限制校验，互斥）；**自定义提示词预设**一键注入 |
| 图生图 | 参考本地图或画布内容编辑；**透明背景**（透明 PNG 输出，5.0 Pro/Flash）；**反推提示词**（参考图 → 结构化提示词 → 填入本页 / 去文生图） |
| 多图融合 | 2-14 张参考图融合 |
| 扩图 / 局部重绘 | 智能扩图、选区局部重绘（画布选区坐标自动填入） |
| 翻译 | 8 种语言互译，**文本图层取原文**联动 |
| 生成图库 | 全部生成记录集中管理：**按功能筛选、多选批量置入、导出 PNG、大图预览** |

与 Photon 深度互动：**从画布取图**（内存读像素，无需导出文件）、**置入画布**（先转智能对象再等比缩放居中，原始像素无损，可反复置入）、**翻译取文本图层原文**。

```
├── doubao-photon-panel/        # 插件本体
│   ├── photon.plugin.json      # 插件清单（面板/命令/权限声明，含版本号）
│   ├── index.html              # 面板界面（Photon 官方设计系统）
│   ├── panel.js                # 面板逻辑（SDK 调用）
│   └── README.txt              # 插件内说明
├── releases/                   # 发布安装包（最新版：doubao-photon-panel-vX.Y.Z.zip）
├── install_plugin.py           # 一键安装脚本（复刻 Photon 注册算法）
├── 一键安装豆包插件.bat        # 双击运行即可安装
└── verify_install.py           # 安装校验脚本
```

## 安装与更新

**安装包**：`releases/` 目录下的 `doubao-photon-panel-vX.Y.Z.zip`（含安装脚本，下载即用）。

1. 下载最新安装包并解压（Windows 右键 → 全部解压缩）
2. **完全退出 Photon Studio**（含托盘图标）
3. 双击解压出的 `一键安装豆包插件.bat`（或运行 `python install_plugin.py`）
4. 重启 Photon，菜单「插件」→「豆包 AI 创作」

**更新**：同一操作重复一遍即可——重新下载最新安装包 → 解压 → 双击 bat，自动覆盖升级（同插件 ID，旧版本自动替换，Key 配置保留）。版本号见 `photon.plugin.json` 的 `version` 字段。

**面板内检查更新**：打开面板会自动检测最新版本（或点右上角「检查更新」按钮），发现新版本会弹出提示并给出下载链接，按提示下载 → 解压 → 双击 bat 即可完成升级。

## 首次使用

1. 打开面板后点右上角「配置 Key」，粘贴你的火山方舟 API Key（形如 `ark-xxxx`），系统加密保存
2. 首次请求时如弹出「Allow endpoint」窗口，点 **Allow**
3. 选择功能页，输入内容即可生成；图片可「置入画布」或「保存到本地」

## 注意事项

- 需火山方舟控制台已开通对应模型服务且账户有额度
- 参考图 Base64 单张上限约 10MB，超大图请先压缩
- API Key 仅存于 Photon 加密凭据系统，代码中无任何明文密钥
- 429 额度超限时会显示中文友好提示（含处理指引）
